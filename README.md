# NotchNow

Notch ala MacBook untuk Windows. NotchNow menyediakan kontrol musik, to-do, kalender, timer, alarm, dan jadwal sholat sesuai lokasi.

**Website & unduhan:** https://darrylfatha.github.io/NotchNow-web/

**Unduh langsung:** [NotchNow-win-x64.zip](https://github.com/darrylfatha/NotchNow-web/releases/latest/download/NotchNow-win-x64.zip) (Windows 10/11, 64-bit)

Repositori ini hanya berisi website unduhan. File aplikasinya ada di halaman [Releases](https://github.com/darrylfatha/NotchNow-web/releases).
