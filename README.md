# NotchNow

Notch ala MacBook untuk Windows. NotchNow menyediakan kontrol musik dengan lirik, to-do dengan pengingat, kalender dengan libur nasional dan cuti bersama, catatan cepat, rak file, riwayat clipboard, peluncur cepat, timer, alarm, dan jadwal sholat sesuai lokasi.

**Website & unduhan:** https://darrylfatha.github.io/NotchNow-web/

**Unduh langsung:** [NotchNow-win-x64.zip](https://github.com/darrylfatha/NotchNow-web/releases/latest/download/NotchNow-win-x64.zip) (Windows 10/11, 64-bit)

**Petunjuk penggunaan:** [Panduan-NotchNow.pdf](panduan/Panduan-NotchNow.pdf) menjelaskan semua fitur langkah demi langkah.

Repositori ini hanya berisi website unduhan dan panduan. File aplikasinya ada di halaman [Releases](https://github.com/darrylfatha/NotchNow-web/releases).
