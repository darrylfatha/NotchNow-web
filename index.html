      Catatan cepat Baru

      Tulis ide atau nomor penting dalam sekejap. Catatan tersimpan otomatis dan bisa disalin. Ctrl+Alt+Q langsung membukanya.

      📂

      Rak file Baru

      Seret file ke notch untuk disimpan sementara, pindah ke jendela lain, lalu seret keluar ke email, chat, atau folder tujuan.

      📋

      Riwayat clipboard Baru

      50 teks dan 8 gambar terakhir yang Anda salin. Klik untuk menyalin ulang, sematkan yang sering dipakai, atau jeda pencatatan.

      🔎

      Peluncur cepat Baru

      Buka aplikasi, hitung, konversi satuan, atau cari di Google dari satu kotak. Tekan Ctrl+Alt+Space dari mana saja.

      Cara pasang

      Siap dalam satu menit.

      1. 1

        Unduh file zip

        Klik tombol Unduh NotchNow untuk mendapatkan NotchNow-win-x64.zip.

      2. 2

        Ekstrak ke folder tetap

        Klik kanan file zip, pilih Extract All, lalu simpan foldernya di tempat yang tidak akan dihapus, misalnya Documents\NotchNow. Biarkan semua file tetap di dalam folder itu.

      3. 3

        Jalankan NotchNow.exe

        Buka folder hasil ekstrak, lalu klik dua kali NotchNow.exe. Bila muncul “Windows protected your PC”, klik More info lalu Run anyway. Peringatan ini muncul karena aplikasi belum ditandatangani digital.

      4. 4

        Arahkan kursor ke atas layar

        Notch hitam muncul di tengah atas layar. Mulai sekarang NotchNow berjalan otomatis setiap Anda login ke Windows.

      FAQ

      Pertanyaan yang sering muncul

      Apakah NotchNow gratis?

      Ya, gratis sepenuhnya, tanpa iklan dan tanpa akun.

      Kenapa Windows menampilkan peringatan SmartScreen?

      Peringatan itu muncul untuk aplikasi yang belum ditandatangani dengan sertifikat digital berbayar. Klik More info → Run anyway untuk menjalankannya.

      Aplikasi musik apa saja yang didukung?

      Semua aplikasi yang tampil di kontrol media Windows, misalnya Spotify, YouTube atau YouTube Music di Chrome/Edge/Brave/Firefox, Media Player, VLC, dan Apple Music.

      Dari mana lirik dan sampul albumnya?

      Lirik diambil dari LRCLIB, database lirik terbuka, dan sampul album dari iTunes. Keduanya dicari otomatis berdasarkan judul dan nama penyanyi, lalu disimpan di cache. Lagu populer umumnya tersedia. Untuk lagu yang tidak ada liriknya akan muncul "Lirik tidak ditemukan", dan bila liriknya tanpa penanda waktu, lirik tampil statis.

      Bagaimana mengatur transparansi dan efek kaca?

      Klik tombol ◐ di kanan atas notch. Slider Latar notch mengatur latar dari transparan sampai gelap, dan slider Efek liquid glass mengatur kekuatan efek kaca dari tipis sampai kuat. Pengaturan disimpan otomatis.

      Bagaimana jadwal sholat menentukan lokasi saya?

      NotchNow memakai layanan lokasi Windows. Bila layanan itu mati, lokasi diperkirakan dari IP. Anda juga bisa memilih Kota manual di tab Sholat. Jadwal diambil dari layanan Aladhan dengan metode Kemenag RI sebagai bawaan.

      Apakah data saya dikirim ke mana-mana?

      Tidak. To-do, catatan, riwayat clipboard, rak file, alarm, dan pengaturan disimpan hanya di komputer Anda (%APPDATA%\NotchNow). Yang dikirim keluar hanya koordinat lokasi untuk jadwal sholat, judul lagu untuk mencari lirik dan sampul, serta kata yang Anda cari lewat peluncur bila Anda memilih pencarian Google. Daftar hari libur diunduh dari kalender publik Google.

      Apa saja pintasan keyboard-nya?

      Ctrl+Alt+N membuka atau menyematkan notch, Ctrl+Alt+Space membuka peluncur (bila kombinasi itu sudah dipakai aplikasi lain, NotchNow memakai Ctrl+Alt+P; pintasan yang aktif tertulis di tab Peluncur), Ctrl+Alt+Q membuka catatan cepat, dan Esc menutup notch atau mematikan alarm.

      Apakah kata sandi yang saya salin ikut tercatat di riwayat clipboard?

      Tidak, bila Anda menyalinnya dari pengelola kata sandi (Bitwarden, 1Password, KeePass, dan sejenisnya), karena aplikasi itu menandai isinya sebagai rahasia. Untuk menyalin hal sensitif dari tempat lain, tekan tombol Jeda di tab Clipboard dulu, atau hapus itemnya setelah selesai.

      Apakah file di rak file ikut tersalin?

      Tidak. Rak hanya menyimpan alamat file, jadi tidak memakan ruang disk. Bila file aslinya dipindah atau dihapus, itemnya di rak ditandai tidak ditemukan.

      Bagaimana cara mematikan auto start atau menghapus aplikasi?

      Klik kanan ikon NotchNow di system tray, lalu hilangkan centang Jalankan saat Windows mulai. Untuk menghapus, hilangkan dulu centang itu, pilih Keluar, lalu hapus folder NotchNow.

      Bagaimana cara memperbarui dari versi lama?

      Klik kanan ikon NotchNow di system tray, pilih Keluar, hapus NotchNow.exe atau folder lamanya, lalu ekstrak zip terbaru dan jalankan NotchNow.exe dari folder baru. To-do, alarm, dan pengaturan tetap tersimpan, dan auto start ikut diperbarui.

      Slider lagu berfungsi di aplikasi apa saja?

      Slider memakai kontrol media Windows, jadi bergantung pada dukungan aplikasi musiknya. Untuk Apple Music, NotchNow punya jalur khusus, dan jendela Apple Music harus tetap terbuka (boleh di-minimize). Bila aplikasi tidak mendukung, slider tampil redup.

      Notch menutupi tab browser saya.

      NotchNow otomatis mengecil menjadi label kecil saat browser atau jendela layar penuh ada di bawahnya. Coba sakelar Simulasi browser terbuka di demo di atas.
