      Fitur

      Semua yang Anda butuhkan, satu notch.

      Jalan otomatis

      NotchNow ikut berjalan setiap kali Windows dinyalakan. Bisa dimatikan dari ikon di system tray.

      ⌨️

      Pintasan keyboard

      Ctrl+Alt+N membuka atau menyematkan notch dari mana saja. Esc menutup notch atau mematikan alarm.

      Cara pasang

      Siap dalam satu menit.

      1. 1

        Unduh file zip

        Klik tombol Unduh NotchNow untuk mendapatkan NotchNow-win-x64.zip.

      2. 2

        Ekstrak ke folder tetap

        Klik kanan file zip, pilih Extract All, lalu simpan foldernya di tempat yang tidak akan dihapus, misalnya Documents\NotchNow.

      3. 3

        Jalankan NotchNow.exe

        Bila muncul “Windows protected your PC”, klik More info lalu Run anyway. Peringatan ini muncul karena aplikasi belum ditandatangani digital.

      4. 4

        Arahkan kursor ke atas layar

        Notch hitam muncul di tengah atas layar. Mulai sekarang NotchNow berjalan otomatis setiap Windows dinyalakan.

      FAQ

      Pertanyaan yang sering muncul

      Apakah NotchNow gratis?

      Ya, gratis sepenuhnya, tanpa iklan dan tanpa akun.

      Kenapa Windows menampilkan peringatan SmartScreen?

      Peringatan itu muncul untuk aplikasi yang belum ditandatangani dengan sertifikat digital berbayar. Klik More info → Run anyway untuk menjalankannya.

      Aplikasi musik apa saja yang didukung?

      Semua aplikasi yang tampil di kontrol media Windows, misalnya Spotify, YouTube atau YouTube Music di Chrome/Edge/Brave/Firefox, Media Player, VLC, dan Apple Music.

      Bagaimana jadwal sholat menentukan lokasi saya?

      NotchNow memakai layanan lokasi Windows. Bila layanan itu mati, lokasi diperkirakan dari IP. Anda juga bisa memilih Kota manual di tab Sholat. Jadwal diambil dari layanan Aladhan dengan metode Kemenag RI sebagai bawaan.

      Apakah data saya dikirim ke mana-mana?

      Tidak. To-do, alarm, dan pengaturan disimpan hanya di komputer Anda (%APPDATA%\NotchNow). Yang dikirim keluar hanya koordinat lokasi, untuk mengambil jadwal sholat.

      Bagaimana cara mematikan auto start atau menghapus aplikasi?

      Klik kanan ikon NotchNow di system tray, lalu hilangkan centang Jalankan saat Windows mulai. Untuk menghapus, pilih Keluar lalu hapus folder NotchNow.

      Notch menutupi tab browser saya.

      NotchNow otomatis mengecil menjadi label kecil saat browser atau jendela layar penuh ada di bawahnya. Coba sakelar Simulasi browser terbuka di demo di atas.
